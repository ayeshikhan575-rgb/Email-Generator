# AI-Powered Cold Email Generator

## Description
This application generates personalized and professional cold emails for job applications using AI.

## Technologies Used
- Python
- LangChain
- Groq Cloud (LLaMA 3)
- ChromaDB
- Streamlit

## Features
- Matches job descriptions with portfolio data
- Generates professional cold emails
- Simple and interactive UI
